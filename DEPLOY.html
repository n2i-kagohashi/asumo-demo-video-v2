ASUMO 動画 v2 — デプロイ引き継ぎ

ビルドは不要です。 リポジトリ直下を静的サイトとして配信すれば、index.html から再生できます。
目次
  1. 取得元
  2. 配信設定
  3. 公開後の確認

取得元

新作専用リポジトリ: github.com/n2i-kagohashi/asumo-demo-video-v2

git clone https://github.com/n2i-kagohashi/asumo-demo-video-v2.git
cd asumo-demo-video-v2

公開中の旧版 n2i-kagohashi/asumo-demo とは別リポジトリです。旧版のブランチ・GitHub Pages設定は変更しないでください。

配信設定

任意の静的ホスティングで、次の設定を使います。

  • Production branch: main
  • Build command: なし
  • Publish directory: リポジトリ直下（.）
  • 入口: /index.html
narration-bookends.wav は約44.6MBです。音声シークのため、HTTP Rangeリクエストに 206 Partial Content を返すホスティングを使用してください。

公開後の確認

curl -I -H "Range: bytes=0-1023" \
  https://公開URL/narration-bookends.wav

206 Partial Content と Accept-Ranges: bytes を確認後、冒頭、16.96秒、220.10秒、末尾へシークして、映像と音声が続くことを確認します。

ローカル確認は python3 _docs/serve_video.py 4322 のあと、http://127.0.0.1:4322/ を開きます。
