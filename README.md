# ASUMO 営業ジャーニー — 新作 v2（確認用）

このブランチは旧版を上書きせず別worktreeで制作した新作です。制作内容・入力の識別・既知の確認事項は [README.html](README.html) を参照してください。AI原稿生成・校了の画面は指定実装で未確認のため、No.39は掲載画面で仮置きです。公開していません。

聖さん向けの公開手順は [DEPLOY.html](DEPLOY.html) を参照してください。新作専用リポジトリへ分離して納品します。

求人広告代理店の営業が触る画面を、リスト作成から請求・入金まで **11工程**ぶん通しでたどる、発表用の疑似動画です。
HTMLのプレイヤーとMP3・提案書PNGで構成され、開始カードをクリックすると再生が始まります（232.2秒、約3分52秒）。

- 新作のローカル確認URL: http://127.0.0.1:4322/ （`python3 _docs/serve_video.py 4322` で起動）
- 旧版の公開URL: https://shofukui-neo.github.io/asumo-demo/ （この新作は反映していません）
- 画面のサンプル情報は旧動画から再利用しています。提案書は指示書で指定された実物PNGを使用しています。

## 見るときの注意

- ブラウザの仕様上、自動再生はしません。開始カードをクリックしてください。
- **ナレーション付きで再生します**（🔇 ボタン、または `M` キーで消せます）。音声は ElevenLabs で収録した `narration.mp3` 1本で、映像と同じタイムラインに焼いてあります。作り直し方は [_audio/README.md](_audio/README.md) を参照してください。
- 全画面は `F` キー。`#t=120` のように付けると、その秒数に頭出しした状態で開始カードが出ます。
- キー操作: `Space` 再生/停止 ／ `←` `→` 5秒 ／ `[` `]` 章の移動 ／ `R` 最初から ／ `C` チャプター。
