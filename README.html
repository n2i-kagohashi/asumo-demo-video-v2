再生・再生成

HTTP Range対応サーバーで開いてください。file:// の直接表示や通常の python -m http.server は、音声シークの確認用には使いません。
cd /Users/kagohashiyu-ki/work/asumo-demo-video-v2
python3 _docs/serve_video.py 4322
# ブラウザで http://127.0.0.1:4322/ を開く

このPCの localhost:4322 には別のIPv6サーバーがあるため、127.0.0.1 を指定します。サーバーはループバックアドレスにのみ待ち受けます。

# この新作のHTMLだけを再生成（元動画と音声は触らない）
python3 _docs/build_codex_video.py
python3 _docs/check_scenes.py
python3 _docs/check_bookends.py
# 結合音声を再生成する場合のみ（保全した元MP3は変更しない）
python3 _docs/build_bookend_audio.py

再生成にはPythonのBeautifulSoup、音声の結合・検算にはFFmpeg、QAにはこのPCに導入済みのChrome／Playwrightを使用。動画自体は静的HTML・WAV・PNGで再生します。新作専用GitHubリポジトリへ納品し、実際のデプロイは行っていません。ASUMO本体への書き込みも行っていません。聖さん向けの公開手順は DEPLOY.html を参照してください。
